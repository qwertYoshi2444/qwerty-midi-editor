# QwertY MIDI Editor

ブラウザ上で動作する、ピアノロール型の MIDI エディタです。  
ノートの追加・移動・削除、複数トラックの管理、MIDIの読み込み・書き出しに対応しています。

[Demo](https://qwertyoshi2444.github.io/piano-roll/)

---

## 特長



* ピアノロールでのノート編集
* 複数トラックの管理
* トラックの音色変更
* リンクトラックでの重ね
* ノートの移動、長さ変更、削除
* ベロシティ編集
* MIDI ファイルの読み込み / 書き出し
* ブラウザだけで動作する静的Webアプリケーション



## 操作


### PC
* 左クリック: ノートを追加
* ドラッグ: ノートを移動
* ノート端をドラッグ: 長さを変更
* 右クリック: ノートを削除
* Select モード: 範囲選択
* Mute モード: ノートをミュート
* Delete モード: ノートを削除
* Space: 再生 / 停止
* Ctrl + C: コピー
* Ctrl + V: ペースト
* Ctrl + X: 切り取り
* Ctrl + マウスホイール: ピアノロール倍率調整
* Ctrl + 上下: オクターブトランスポーズ
* Shift + 上下: 半音トランスポーズ

### モバイル
* タップ: ノートを追加 / ノートを選択
* ドラッグ（1本指）: ノートを移動 / 範囲選択 / ノートをミュート / ノートを削除
* ドラッグ（2本指）: ピアノロール移動 / 倍率調整
* ノート端をドラッグ: 長さを変更

※右下のボタンでコピーやトランスポーズが可能
