# QwertY MIDI Editor

ブラウザ上で動作する、ピアノロール型の簡易的なMIDIエディタです。  
ノートの追加・移動・削除、複数トラックの管理、MIDIの読み込み・書き出しに対応しています。

[Open QwertY MIDI Editor↗](https://qwertyoshi2444.github.io/piano-roll/)

---

## 1.UI要素

### キャンバス（画面中央）

自由にノートを配置することができます。

左側にある鍵盤には現在再生されている箇所がハイライトされ、また鍵盤をタップすることでその音を鳴らすことも可能。



### ツールバー（画面上部）

トラックパネルの開閉や音声の再生、モード選択、グローバル設定、ファイルのインポート/エクスポートを行うツールが並んでいます。



### トラックパネル（画面左側）

複数トラックがリスト形式で表示され、トラックの設定・追加ができます。

各トラックの左下にある`=`のマークをドラッグ（モバイルの場合はホールドしてからスライド）させると順番を入れ替えが可能。

## 2.操作・モード説明

### Drawモード

主にノートの編集を行うモードです。

* ノート追加: キャンバス上でクリック / タップ
* ノート移動: ノートが選択された状態でノートをドラッグ / 1本指でドラッグ
* ノート伸縮: ノートが選択された状態でノートの後ろをドラッグ / 1本指でドラッグ
* ノート削除（PCのみ）: ノートを右クリック　※右クリック中になぞると連続で削除可

### Selectモード

ノートを複数選択するモードです。

* ノート選択: キャンバス上でドラッグ / 1本指でドラッグ
（このとき、バウンディングボックス内をDrawモードでドラッグすることでもノートの移動が可能）


### Muteモード

任意のノートをミュートにするモードです。

* ミュート: ノートをクリック / タップ　※なぞると連続でミュート可


### Deleteモード

任意のノートを削除するモードです。

* 削除: ノートをクリック / タップ　※なぞると連続で削除可


### グローバル設定

  #### スナップ

  キャンバス上でのノートのスナップ幅を指定します。
  デフォルトは16部音符、最大で1小節から、スナップをオフにすることも可能。

  #### BPM

  楽曲のBPMを指定します。
  20~300までの整数値で指定可能。

  #### トランスポーズ

  楽曲全体をトランスポーズします。
  -24~24までの整数値で指定可能。

  #### ボリューム

  楽曲全体のプレビュー音量を調節します。
  デフォルトの音量でスナップします。



### キャンバス操作

* キャンバス移動: ホイール長押しでドラッグ / 2本指でスライド（パン）
* キャンバス拡大縮小: Ctrl + マウスホイール / 2本指でピンチイン・アウト



### PC向けショートカット

* Space: 再生 / 停止
* Ctrl + C: コピー
* Ctrl + V: ペースト
* Ctrl + X: 切り取り
* Ctrl + マウスホイール: ピアノロール倍率調整
* Ctrl + 上下キー: オクターブトランスポーズ
* Shift + 上下キー: 半音トランスポーズ

### モバイル向け操作パネル

画面右下に表示される8つのボタンから、コピーやトランスポーズ等の操作を行えます。

* ⧉: コピー
* ✂️: 切り取り
* 📋: ペースト
* 🧽: 削除
* +12/-12: オクターブトランスポーズ
* +1/-1: 半音トランスポーズ

## 3.トラック設定

### 音量バー

トラックの再生音量を設定します。デフォルトの音量にスナップします。


### ミュート、ソロ（M/S）

Mボタンでそのトラックをミュート、Sボタンでそのトラックのみ再生（ソロ化）します。
リファレンストラックでも同様にミュート、ソロが可能。


### 音色設定

* トランスポーズ: -48~48半音の範囲で、トラック内全ての音を一律にトランスポーズします。出力されるファイルではトランスポーズ後の音程で保存されます。
* 波形: Sawtooth、Square、Triangle、Sine、Pulse 25%、Pulse 12.5%、Noiseの7種から選択可能。
* ADSRノブ: 各ノートのAttack、Decay、Sustain、Releaseを設定します。ノブの値は非線形マッピングにより小さい値での調整がより容易になっています。

### トラック色

トラックの色を32色の中から選んで変更します。
トラックリストでの表示色と、キャンバス上のノートの色が変更されます。

### トラック名

トラック名を変更します。
トラック名は出力されるMIDIファイルにも反映されます。

## 4.特殊トラック

### リファレンストラック

音声ファイルを読み込み、プレビュー時に同時再生することができます。耳コピなどに便利です。

音源の読み込みと音量調節は、トラックパネル最上部のリファレンストラックから行えます。


### リンクトラック

各トラックの` ⋮ `ボタンから、リンクトラックを作成することができます。
リンクトラックはリンク元の音程をそのままコピーし、個別に音色やトランスポーズを変更できます。

オクターブハモリなどを作成する際、複数トラックを個別に編集する手間を減らせます。

## 5.ファイルのインポート/エクスポート

### インポート

お手持ちの`.mid`ファイルをインポートします。
既存データを上書きするか、新規トラックとして追加するかを選択できます。

インポートする際にリンクトラックの保持を選択すると、トラック名を参照し、リンク関係とリンクトラックのトランスポーズが復元されます。

別のツールでリンクトラック付きMIDIを編集した場合、リンク関係を正常に復元できない場合があります。

**※MIDIファイルのベロシティ、ピッチベンド、コントロールチェンジ、楽器情報などは、読み込み時に破棄されます。**


### エクスポート

  #### 標準エクスポート
  
  設定したトラック名を含んだシンプルなMIDIファイルとして出力します。
  リンクトラックを含むすべてのトラックについて、トランスポーズ適用後の音程で保存されます。
  
  **※音色設定やADSR設定、リンクトラックの依存関係は保存されません。**
  
  
  
  #### リンクトラック付きエクスポート
  
  リンクトラックのトランスポーズ情報を含んだMIDIファイルとして出力します。
  リンクトラックの情報はトラック名に保存されます。
  
  **※音色設定やADSR設定は保存されません。**
