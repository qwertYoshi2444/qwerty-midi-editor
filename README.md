# QwertY MIDI Editor

ブラウザ上で動作する、ピアノロール型の MIDI エディタです。  
ノートの追加・移動・削除、複数トラックの管理、MIDIの読み込み・書き出しに対応しています。

[Open QwertY MIDI Editor↗](https://qwertyoshi2444.github.io/piano-roll/)

---

## 1.特長

* ブラウザだけで動作する静的Webアプリケーション
* ピアノロールでのノート編集
* 複数トラックの管理
* トラックの音色変更
* リンクトラックでのオクターブ重ね、簡易的なハモリ作成
* MIDI ファイルの読み込み / 書き出し

## 2.操作

#### PC
* 左クリック: ノートを追加
* ドラッグ: ノートを移動
* ノート端をドラッグ: 長さを変更
* 右クリック: ノートを削除
* Select モード: 範囲選択
* Mute モード: ノートをミュート
* Delete モード: ノートを削除
* Space: 再生 / 停止
* Ctrl + C: コピー
* Ctrl + V: ペースト
* Ctrl + X: 切り取り
* Ctrl + マウスホイール: ピアノロール倍率調整
* Ctrl + 上下: オクターブトランスポーズ
* Shift + 上下: 半音トランスポーズ

#### モバイル
* タップ: ノートを追加 / ノートを選択 / ノートをミュート / ノートを削除
* ドラッグ（1本指）: ノートを移動 / 範囲選択 / ノートをミュート / ノートを削除
* ドラッグ（2本指）: ピアノロール移動 / 倍率調整
* ノート端をドラッグ: 長さを変更

※右下のボタンでコピーやトランスポーズが可能

## 3.トラック設定

### 音量バー
トラックの再生音量を設定します。デフォルトの音量にスナップします。
#### ミュート、ソロ（M/S）
Mボタンでそのトラックをミュート、Sボタンでそのトラックのみ再生（ソロ化）します。
リファレンス音声でも同様にミュート、ソロが可能。
### 音色設定
* トランスポーズ: -48～48半音の範囲で、トラック内全ての音を一律にトランスポーズします。出力されるファイルではトランスポーズ後の音程で保存されます。
* 波形: Sawtooth、Square、Triangle、Sine、Pluse 25%、Pulse 12.5%、Noiseの7種から選択可能。
* ADSRノブ: 各ノートのAttack、Decay、Sustain、Releaseを設定します。ノブの値は非線形マッピングにより小さい値での調整がより細かく可能。
### トラック色
トラックの色を32色の中から選んで変更します。トラックリストでの表示色と、ピアノロール上のノートの色が変更されます。
### トラック名
トラック名を変更します。出力されるMIDIファイルにも反映されます。
